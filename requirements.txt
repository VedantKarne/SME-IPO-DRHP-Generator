# ── 9. Embeddings — Metal / MPS Accelerated ──────────────────
#
# [MPS] PyTorch — standard macOS arm64 wheel includes MPS backend.
#   DO NOT add --index-url or install the CPU-only wheel.
#   MPS gives GPU acceleration via Metal on all M-series chips.
#   Requirement: macOS 12.3+ (you are on 26.5.2 — fully supported).
torch                       # MPS backend auto-enabled on Apple M5 via Metal
#
# [MPS] HuggingFace Accelerate — handles MPS device placement for
#   transformer models including FlagEmbedding / BGE-M3.
#   Without this, device dispatch may silently fall to CPU.
accelerate                  # HuggingFace device placement — enables MPS dispatch for FlagEmbedding
#
# [MPS] FlagEmbedding — BGE-M3 dual-encoder (dense + sparse).
#   Internally uses torch; will use MPS automatically when torch MPS is active.
#   use_fp16=True (already set in bge_m3_embedder.py) works correctly on M-series.
FlagEmbedding               # `from FlagEmbedding import BGEM3FlagModel` — bge_m3_embedder.py


# ── 10. Re-ranking — CoreML / ANE Accelerated ────────────────
#
# [CoreML] ONNX Runtime — FlashRank uses onnxruntime internally to run
#   the MiniLM cross-encoder (ms-marco-MiniLM-L-12-v2) stored in ./models/.
#   On macOS arm64, the official onnxruntime wheel now ships with the
#   CoreML Execution Provider (delegates to Apple Neural Engine + GPU).
#   No longer need onnxruntime-silicon (deprecated community build).
#   CoreML EP is activated at session creation — not pip-level config.
onnxruntime                 # CoreML EP included in arm64 wheel — offloads FlashRank to ANE/GPU
flashrank                   # `from flashrank import Ranker, RerankRequest` — flashrank_reranker.py
#   flashrank installs onnxruntime as a transitive dep; pinning it above
#   ensures arm64 wheel is resolved first.
